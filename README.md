Home Lab

A hands-on home lab built on Ubuntu Server for exploring networking tools and self-hosted infrastructure.

Overview

This lab is where I learn how networking tools and services work by setting them up, configuring them, and breaking them. It is separate from my security work and focuses on general networking and systems administration.
